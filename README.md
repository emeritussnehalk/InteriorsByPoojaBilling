# Pooja Interior Ledger

A static interior quotation builder for GitHub Pages.

## Features

- Fill client, company, room, item, material, and payment slab details.
- Add, edit, and delete areas, line items, and payment slabs.
- Auto-calculate square feet, item amount, work total, designer fees, and grand total.
- Download a formatted PDF quotation.
- Upload a PDF generated by this app to reload the editable form.

The app does not use a database or browser save storage. The editable quote data is embedded inside PDFs generated by the app.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.
